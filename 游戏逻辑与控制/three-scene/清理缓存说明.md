# 清理缓存说明

## 问题
如果遇到 "Failed to resolve module specifier 'three'" 错误，可能是浏览器或 Vite 缓存了旧文件。

## 解决步骤

### 1. 停止开发服务器
按 `Ctrl+C` 停止当前运行的 Vite 开发服务器

### 2. 清理缓存（手动）
删除以下目录（如果存在）：
- `node_modules/.vite/` - Vite 缓存目录
- `dist/` - 构建输出目录

### 3. 重启开发服务器
```bash
npm run dev
```

### 4. 清理浏览器缓存
在浏览器中：
- 按 `Ctrl+Shift+Delete` 打开清除数据对话框
- 选择"缓存的图像和文件"
- 点击"清除数据"

或者：
- 按 `Ctrl+F5` 硬刷新页面
- 或按 `Ctrl+Shift+R` 强制刷新

### 5. 检查控制台
打开浏览器开发者工具（F12），查看控制台是否还有错误。

## 如果问题仍然存在

请检查：
1. 所有 Three.js 导入是否都使用 CDN 路径（已修复）
2. GLB 文件是否在 `public/models/` 目录下（已确认）
3. 网络连接是否正常（CDN 访问）
