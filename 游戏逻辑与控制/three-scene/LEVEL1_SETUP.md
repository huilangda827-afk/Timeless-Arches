4. **已更新 `src/main.js`** - 添加调试交互

## 🚀 快速开始

### 步骤 1: 安装依赖

```bash
cd "游戏逻辑与控制/three-scene"
npm install
```

这会安装 `lil-gui` 调试工具库。

### 步骤 2: 准备模型文件

将以下 GLB 模型文件放入 `public/` 目录：

- `大斗-底层.glb` (基座，不可动)
- `正心瓜拱-中层.glb`
- `华拱高层.glb`
- `散斗左上角.glb`
- `散斗-右上角.glb`

### 步骤 3: 启动项目

```bash
npm run dev
```

在浏览器中打开显示的地址（通常是 `http://localhost:5173`）

### 步骤 4: 启用调试模式

1. 在浏览器中按 **`D`** 键启用调试 GUI
2. 调试面板会显示在右上角

### 步骤 5: 选择构件进行调试

1. **按住 `Shift` 键 + 点击构件**
2. 构件会被选中，调试 GUI 会显示该构件的坐标
3. 如果点击空白处，会清除选择

### 步骤 6: 调整坐标

1. 在调试 GUI 中使用 X, Y, Z 滑块调整构件位置
2. 实时查看构件在场景中的位置变化
3. 控制台会实时输出当前坐标

### 步骤 7: 复制坐标

1. 调整到正确位置后，点击 **"复制坐标到控制台"** 按钮
2. 坐标会以代码格式输出到控制台，例如：
   ```
   new THREE.Vector3(0.000, 0.600, 0.000)
   ```
3. 也可以从控制台直接看到格式化的坐标

### 步骤 8: 更新配置文件

1. 打开 `src/core/levels/Level1Config.js`
2. 将校准后的坐标替换相应的 `targetPosition`
3. 保存文件，页面会自动热重载
4. 重复步骤 5-8，校准所有构件

## 🎮 快捷键说明

| 快捷键 | 功能 |
|--------|------|
| `D` | 切换调试模式（显示/隐藏调试 GUI） |
| `Shift + 点击构件` | 选择构件进行调试 |
| `Shift + 点击空白处` | 清除选择的构件 |

## 📐 坐标系统说明

- **原点**：场景中心 `(0, 0, 0)`
- **Y 轴**：向上递增
- **基座位置**：通常 Y = 0
- **构件堆叠**：根据结构图，Y 坐标应递增

### 预估坐标参考（需要校准）

根据结构图的垂直堆叠关系：

- **基座** (`大斗-底层.glb`): `(0, 0, 0)`
- **Layer 1** (`正心瓜拱-中层.glb`): `(0, 0.6, 0)` - 需要校准
- **Layer 2** (`华拱高层.glb`): `(0, 1.2, 0)` - 需要校准
- **Layer 3 左侧** (`散斗左上角.glb`): `(-0.5, 1.8, 0)` - 需要校准
- **Layer 3 右侧** (`散斗-右上角.glb`): `(0.5, 1.8, 0)` - 需要校准

## 🔧 调试 GUI 功能

调试 GUI 面板包含以下功能：

1. **X, Y, Z 滑块**：调整构件位置（范围 -10 到 10，精度 0.01）
2. **复制坐标到控制台**：输出格式化的坐标代码
3. **重置为初始值**：恢复到构件原始位置
4. **启用调试**：切换调试模式开关

## 📝 配置文件结构

```javascript
export const level1Config = {
  snapThreshold: 0.3,        // 吸附阈值
  base: {                     // 基座配置
    modelPath: "...",
    targetPosition: Vector3,
    isInteractive: false,     // 基座不可交互
  },
  pieces: [                   // 构件数组
    {
      modelPath: "...",
      targetPosition: Vector3, // ⚠️ 需要校准
      isInteractive: true,
      pieceId: 0,
      slotId: 0,
      displayName: "...",
      startPosition: Vector3,  // 初始散落位置
    },
    // ... 更多构件
  ],
};
```

## ⚠️ 注意事项

1. **模型文件路径**：确保 GLB 文件在 `public/` 目录下，路径大小写敏感
2. **坐标精度**：建议保留 3 位小数
3. **基座不可动**：`base.isInteractive` 必须为 `false`
4. **顺序重要**：构件的 `pieceId` 和 `slotId` 需要匹配
5. **Y 轴递增**：确保构件的 Y 坐标按堆叠顺序递增

## 🐛 故障排除

### 调试 GUI 不显示

- 检查是否按了 `D` 键
- 查看控制台是否有错误
- 确认 `lil-gui` 已正确安装

### 点击构件无反应

- 确保按住 `Shift` 键
- 检查构件是否在相机视野内
- 查看控制台错误信息

### 坐标不更新

- 检查控制台是否有 JavaScript 错误
- 确认构件对象是否正确选中
- 尝试刷新页面
