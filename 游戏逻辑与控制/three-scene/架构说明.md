## 核心算法

### 坐标映射 (2D → 3D)

```javascript
// 1. 屏幕坐标 → NDC 坐标
const ndc = new THREE.Vector2(
  ((clientX - rect.left) / rect.width) * 2 - 1,   // x: -1 ~ 1
  -((clientY - rect.top) / rect.height) * 2 + 1   // y: -1 ~ 1
);

// 2. NDC + 相机 → Raycaster
raycaster.setFromCamera(ndc, camera);

// 3. 与深度平面求交（或与构件求交）
const hitPoint = raycaster.intersectPlane(
  depthPlane,  // 动态深度平面（可滚轮调节）
  intersectionPoint
);
```

### 磁吸算法

```javascript
// 渐进式吸附
function trySnap(piece, slot, deltaTime) {
  const distance = piece.position.distanceTo(slot.position);
  const angleDiff = Math.abs(piece.rotation.y - slot.rotation.y);
  
  if (distance < snapDistance && angleDiff < snapAngleRad) {
    // 计算吸附强度（距离越近，强度越大）
    const strength = 1 - (distance / snapDistance);
    
    // 平滑插值位置
    piece.position.lerp(slot.position, strength * 0.15 * deltaTime * 60);
    
    // 平滑插值旋转
    piece.rotation.y = THREE.MathUtils.lerp(
      piece.rotation.y,
      slot.rotation.y,
      strength * 0.15 * deltaTime * 60
    );
    
    // 完全吸附判定
    if (distance < 0.1 && angleDiff < 0.05) {
      piece.position.copy(slot.position);
      piece.rotation.copy(slot.rotation);
      return true; // 吸附成功
    }
  }
  return false;
}
```

### Z-Index 层级

```
z-index: 10000+  →  UI 按钮和交互元素
z-index: 2001    →  模态框（登录、设置）
z-index: 1001    →  主菜单
z-index: 1000    →  UI Layer 容器
z-index: 0       →  Three.js Canvas
```

## 文件组织原则

1. **模块化**: 每个模块职责单一，通过接口交互
2. **解耦**: 模块之间通过回调函数通信，避免直接依赖
3. **可扩展**: 新功能通过新增模块实现，不影响现有代码
4. **可测试**: 模块可独立测试，便于调试

## 性能考虑

1. **模型加载**: 异步加载，使用 Promise 管理
2. **渲染优化**: 只更新变化的物体，避免每帧全量更新
3. **事件节流**: 手势更新频率限制在 30Hz
4. **内存管理**: 及时清理不再使用的对象和事件监听器

## 扩展建议

### 添加新关卡

1. 创建 `LevelXConfig.js` 配置文件
2. 在 `main.js` 中加载新配置
3. 无需修改其他模块代码

### 添加新特效

1. 在 `EffectManager` 中添加新特效方法
2. 在需要的地方调用该方法

### 添加新 UI 页面

1. 在 `index.html` 中添加 HTML 结构
2. 在 `UIManager` 中添加显示/隐藏方法
3. 在 `style.css` 中添加样式
