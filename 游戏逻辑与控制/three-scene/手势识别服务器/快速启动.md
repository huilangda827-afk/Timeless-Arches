# 手势识别服务器 - 快速启动指南

## 🚀 快速启动（Windows）

### 方法1：使用批处理脚本（推荐）

1. **双击运行** `启动服务器.bat`（如果存在）
2. 或者打开 PowerShell/CMD，运行：
```bash
cd "游戏逻辑与控制\three-scene\手势识别服务器"
python server.py
```

### 方法2：手动启动

1. **打开终端**（PowerShell 或 CMD）
2. **进入服务器目录**：
```bash
cd "游戏逻辑与控制\three-scene\手势识别服务器"
```

3. **安装依赖**（如果还没安装）：
```bash
pip install -r requirements.txt
```

4. **启动服务器**：
```bash
python server.py
```

5. **看到以下信息表示成功**：
```
[服务器] 正在启动 WebSocket 服务器...
[服务器] 地址: ws://localhost:12345
[服务器] 等待客户端连接...
[服务器] 客户端已连接: ...
[服务器] ✅ 摄像头已启动
```

## ⚠️ 常见问题

### 问题1：找不到 python 命令

**解决方案**：
- 确保已安装 Python 3.7+
- 尝试使用 `python3` 代替 `python`
- 或者使用完整路径：`C:\Python39\python.exe server.py`

### 问题2：摄像头无法打开

**解决方案**：
- 检查摄像头是否被其他程序占用
- 尝试关闭其他使用摄像头的应用（如 Zoom、Teams 等）
- 检查摄像头权限设置

### 问题3：依赖安装失败

**解决方案**：
```bash
# 升级 pip
python -m pip install --upgrade pip

# 单独安装依赖
pip install mediapipe
pip install opencv-python
pip install websockets
```

### 问题4：端口被占用

**解决方案**：
- 检查是否有其他程序使用 12345 端口
- 可以修改 `server.py` 中的端口号（第174行）

## 📝 使用说明

1. **启动服务器后**，保持终端窗口打开
2. **刷新浏览器页面**，手势识别会自动连接
3. **在浏览器控制台**可以看到连接状态：
   - `[HandInput] WebSocket 已连接` - 连接成功
   - `[HandInput] WebSocket 连接失败...` - 服务器未运行

## 🎮 手势操作

- **张开手掌**：移动光标
- **握拳**：抓取构件
- **张开手掌**：释放构件
- **拇指指向**：旋转构件（如果已实现）

## 🔧 停止服务器

按 `Ctrl + C` 停止服务器

---

**提示**：如果手势识别服务器未运行，游戏会自动使用鼠标模式，这是正常的！
