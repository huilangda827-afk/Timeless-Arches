# WebSocket 连接说明

## 📡 WebSocket 连接状态

### 当前状态

应用会尝试连接到 `ws://localhost:12345`，这是**手势识别服务器**的地址。

### 连接失败是正常的

如果看到以下消息：
```
[HandInput] WebSocket 连接失败（手势识别服务器未运行，这是正常的）
```

**这是完全正常的**，因为：
1. 手势识别服务器是**可选的**功能
2. 如果没有运行服务器，应用会**自动使用鼠标模式**
3. 不影响主菜单按钮和其他 UI 交互

### 当前模式

- **鼠标模式**：可以使用鼠标拖拽和旋转 3D 构件
- **手势模式**：需要启动手势识别服务器（可选）

---

## 🚀 如何启动手势识别服务器（可选）

如果您想使用手势识别功能，需要：

1. **启动手势识别服务器**（通常是 Python 脚本）
2. 服务器应该监听 `localhost:12345` 端口
3. 服务器应该通过 WebSocket 发送手势数据

### 服务器要求

- **地址**：`ws://localhost:12345`
- **数据格式**：JSON 格式，包含 `{ gesture, x, y }` 字段

---

## 🔧 配置

如果需要修改 WebSocket 地址，可以在 `src/main.js` 中修改：

```javascript
const CONFIG = {
  // ...
  wsUrl: "ws://localhost:12345", // 修改这里
  wsRetryMs: 900, // 重连间隔（毫秒）
  // ...
};
```

---

## ✅ 验证

### 检查当前模式

查看页面左上角的调试信息：
- `Input: mouse` → 鼠标模式（正常）
- `Input: gesture` → 手势模式（需要服务器运行）

### 测试交互

1. **鼠标模式**：
   - 点击"开始筑梦"进入游戏
   - 使用鼠标拖拽 3D 构件
   - 使用鼠标滚轮旋转构件

2. **手势模式**（需要服务器）：
   - 握拳抓取构件
   - 张开手掌释放构件
   - 拇指左右旋转构件

---

## 📝 注意事项

1. **WebSocket 连接失败不影响主功能**
   - 主菜单按钮应该可以正常点击
   - 3D 场景应该可以正常交互
   - 只是无法使用手势识别

2. **减少日志噪音**
   - 现在只在第一次断开时显示警告
   - 后续会静默重连，不会刷屏

3. **如果按钮仍然无法点击**
   - 问题不在 WebSocket
   - 请检查控制台是否有其他错误
   - 请告诉我具体的错误信息
