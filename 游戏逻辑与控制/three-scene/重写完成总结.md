## 🔧 如果遇到问题

### 摄像头打不开

1. **检查摄像头权限**：
   - Windows：设置 → 隐私 → 相机
   - 确保应用有摄像头权限

2. **检查摄像头是否被占用**：
   - 关闭其他使用摄像头的应用（Zoom、Teams等）

3. **尝试不同的摄像头索引**：
   - 修改 `server.py` 中的 `CAMERA_INDEX`（0, 1, 2...）

### 模型看不到

1. **检查浏览器控制台**：
   - 查看是否有模型加载错误
   - 检查模型文件路径是否正确

2. **检查模型文件**：
   - 确认 `public/models/` 目录下有所有模型文件
   - 文件名必须与 `Level1Config.js` 中的配置匹配

3. **检查相机位置**：
   - 尝试使用鼠标滚轮缩放
   - 尝试拖拽旋转视角

### 模型动不了

1. **检查控制台日志**：
   - 查看是否有点击检测的日志
   - 检查是否有错误信息

2. **检查渲染器交互**：
   - 确保游戏已开始（主菜单已隐藏）
   - 检查 `pointer-events` 是否为 `auto`

3. **尝试备用检测**：
   - 如果直接点击检测不到，系统会自动尝试附近检测
   - 查看控制台的调试信息

## 📝 技术细节

### 坐标转换修复

**问题**：服务器发送的是 0-1 范围的归一化坐标，但 Three.js 需要 -1 到 1 的 NDC 坐标。

**修复**：
```javascript
// 服务器发送：x, y 在 0-1 范围
// Three.js 需要：NDC 坐标在 -1 到 1 范围
const rx = (g.x * 2) - 1;  // 0-1 -> -1 到 1
const ry = 1 - ((g.y * 2) - 1);  // 0-1 -> 1 到 -1（Y轴翻转）
```

### 手势检测改进

**之前**：复杂的手势判断，容易出错

**现在**：简化为三种手势：
- `open`：所有手指伸直
- `fist`：握拳
- `point`：指向（只有食指伸直）

### 交互优先级

**规则**：
1. 鼠标拖拽时，手势不响应
2. 手势拖拽时，鼠标不响应
3. 避免冲突和混乱
