# 斗拱拼装游戏实现说明

## 📋 概述

已实现完整的斗拱拼装游戏系统，基于 GLTF 模型的交互式拼装游戏。玩家可以将散落的斗拱组件拖拽到正确的位置，通过"幽灵参照物"实现自动吸附。

## 🎯 核心功能

### 1. 静态环境加载
- **文件**: `背景版.glb`
- **位置**: 世界原点 (0, 0, 0)
- **状态**: 不可交互，静态显示

### 2. 幽灵参照解析
- **文件**: `幽灵组件.glb`
- **功能**: 自动解析所有名称包含"配套"的子节点
- **提取信息**: 世界坐标、旋转、缩放
- **存储**: `TARGET_CONFIG` 字典，格式：
  ```javascript
  {
    "大斗": { pos: Vector3, quat: Quaternion, isOccupied: false },
    "华拱": { ... },
    ...
  }
  ```

### 3. 玩家组件生成
- **组件列表**: `['大斗', '华拱', '正心瓜拱', '散科-左边', '散科-右边']`
- **初始位置**: 停靠区（相机前方，避免与中央红柱子重叠）
- **身份绑定**: 每个组件都有 `userData.partID` 标识

### 4. 拖拽与吸附
- **交互方式**: 鼠标/触摸拖拽
- **吸附阈值**: 0.4 米
- **吸附逻辑**: 
  - 计算组件与目标位置的距离
  - 距离 < 0.4 米时自动吸附
  - 锁定组件，标记目标为已占用
  - 播放吸附音效

### 5. 相机配置
- **位置**: `(10.79, 2.76, 0.42)` (基于 Blender 坐标转换)
- **观察点**: `(0, 2.0, 0)` (红色立柱顶端)
- **约束**:
  - `minDistance = 2`
  - `maxDistance = 20`
  - `maxPolarAngle = π/2` (防止钻入地底)

## 🚀 使用方法

### 基本使用

```javascript
import { DouGongGame } from "./core/DouGongGame.js";

// 创建游戏实例
const game = new DouGongGame({
  snapDistance: 0.4,           // 吸附距离阈值
  dockingArea: { x: -5, y: 0, z: -5 }  // 停靠区位置
});

// 初始化
await game.init(document.body);

// 启动渲染循环
game.animate();
```

### 配置选项

- `snapDistance`: 吸附距离阈值（默认 0.4 米）
- `dockingArea`: 停靠区位置（默认 `{ x: -5, y: 0, z: -5 }`）

## 🎮 交互说明

### 鼠标操作
1. **拖拽**: 鼠标左键点击并拖拽组件
2. **吸附**: 将组件拖到目标位置附近（距离 < 0.4 米）自动吸附
3. **相机控制**: 使用 OrbitControls 旋转、缩放视图

### 触摸操作（移动端）
- 支持单点触摸拖拽
- 交互逻辑与鼠标相同

## 🔧 技术细节

### 坐标系
- **静态环境**: 世界原点对齐 (World Origin Aligned)
- **幽灵参照**: 世界原点对齐 (World Origin Aligned)
- **玩家组件**: 局部归零 (Local Centered)

### 世界坐标提取
在解析幽灵参照时，系统会：
1. 将模型添加到场景
2. 调用 `updateMatrixWorld(true)` 更新矩阵
3. 使用 `getWorldPosition()` 和 `getWorldQuaternion()` 提取世界坐标

### 吸附判定
```javascript
const distance = part.position.distanceTo(target.pos);
if (distance < this.snapDistance) {
  // 执行吸附
  part.position.copy(target.pos);
  part.quaternion.copy(target.quat);
  part.userData.isDraggable = false;
  target.isOccupied = true;
}
```
