# 斗拱拼装系统 - 技术问题总结与交接文档

## 项目概述
基于 Three.js + MediaPipe Hands 的 3D 斗拱拼装交互系统，通过手势识别实现组件的抓取、移动和吸附拼装。

---

## 一、核心问题总结

### 问题 1：鼠标滚轮缩放功能未实现

#### 问题描述
用户无法通过鼠标滚轮放大/缩小场景，影响精细操作体验。

#### 当前实现状态
```javascript
// main.js:99-103
controls.enableZoom = true;
controls.zoomSpeed = 1.0;
controls.enablePan = true;
controls.enableRotate = true;

// main.js:561-567
if (renderer) {
  renderer.domElement.style.pointerEvents = 'auto';
  if (controls) {
    controls.enabled = true;
  }
}
```

#### 问题根因分析
1. **CSS pointerEvents 冲突**：
   - 初始状态：`renderer.domElement.style.pointerEvents = 'none'` (line 87)
   - 仅在点击"开始筑梦"按钮后才设置为 `'auto'`
   - 可能存在 UI 层遮挡或事件冒泡问题

2. **OrbitControls 事件绑定时机**：
   - OrbitControls 在初始化时绑定到 `renderer.domElement`
   - 但此时 `pointerEvents = 'none'`，可能导致事件监听器未正确注册

3. **可能的 UI 层干扰**：
   - `#ui-layer` 或其他 UI 元素可能拦截了滚轮事件
   - z-index 层级问题

#### 解决方案建议
1. **确保事件传递**：
   ```javascript
   // 在初始化时确保 pointerEvents 设置
   renderer.domElement.style.pointerEvents = 'auto'; // 或根据状态动态切换
   
   // 添加显式滚轮事件监听（作为备用）
   renderer.domElement.addEventListener('wheel', (e) => {
     if (controls && controls.enabled) {
       controls.handleWheel(e); // 手动触发 OrbitControls 的滚轮处理
     }
   }, { passive: false });
   ```

2. **检查 UI 层 CSS**：
   ```css
   /* 确保 UI 层不拦截滚轮事件 */
   #ui-layer {
     pointer-events: none; /* 或 auto，但子元素需要明确设置 */
   }
   #ui-layer > * {
     pointer-events: auto; /* 子元素可交互 */
   }
   ```

3. **添加调试日志**：
   ```javascript
   renderer.domElement.addEventListener('wheel', (e) => {
     console.log('[Debug] 滚轮事件触发', e.deltaY);
   });
   ```

### 问题 2：肉眼位置合适但显示拼接失败

#### 问题描述
组件在视觉上已接近目标位置，但系统判定为未完成，显示拼接失败。

#### 当前实现状态
```javascript
// main.js:37
const SNAP_DISTANCE = 2.0; // 吸附阈值 2.0 米

// main.js:430-443 (吸附判定)
if (distance < SNAP_DISTANCE) {
  const angleDiff = pieceQuat.angleTo(target.quaternion);
  if (distance < 1.0 || angleDiff < SNAP_ANGLE_THRESHOLD) {
    shouldSnap = true; // 触发吸附
  }
}

// main.js:474-499 (完成验证)
const allSnapped = interactivePieces.every(p => {
  const dist = p.position.distanceTo(target.position);
  if (dist > 0.5) { // ⚠️ 验证时要求 < 0.5 米
    return false; // 未真正完成
  }
  const angleDiff = pieceQuat.angleTo(target.quaternion);
  if (angleDiff > Math.PI / 6) { // 30度
    return false;
  }
  return true;
});
```

#### 问题根因分析
1. **阈值不一致**：
   - 吸附阈值：`SNAP_DISTANCE = 2.0` 米（过于宽松）
   - 完成验证阈值：`0.5` 米（过于严格）
   - **矛盾**：组件可以在 2.0 米内吸附，但验证时要求 < 0.5 米才算完成

2. **视觉感知 vs 实际距离**：
   - 3D 场景中的视觉距离受相机视角、FOV、透视影响
   - 用户看到的"合适"可能是 1.5-2.0 米，但验证要求 0.5 米

3. **角度检查过于严格**：
   - 完成验证要求角度差 < 30 度
   - 但吸附时如果距离 < 1.0 米会忽略角度
   - 可能导致吸附成功但角度不对，验证失败

#### 解决方案建议
1. **统一阈值**：
   ```javascript
   const SNAP_DISTANCE = 0.8; // 吸附阈值（精确）
   const COMPLETION_DISTANCE = 0.6; // 完成验证阈值（略大于吸附阈值）
   const COMPLETION_ANGLE = Math.PI / 4; // 45度（更宽松）
   
   // 吸附判定
   if (distance < SNAP_DISTANCE) {
     if (distance < 0.3 || angleDiff < SNAP_ANGLE_THRESHOLD) {
       shouldSnap = true;
     }
   }
   
   // 完成验证
   if (dist > COMPLETION_DISTANCE) {
     return false;
   }
   if (angleDiff > COMPLETION_ANGLE) {
     return false;
   }
   ```

2. **添加视觉反馈**：
   ```javascript
   // 当距离接近但未完成时，显示提示
   if (dist > COMPLETION_DISTANCE && dist < COMPLETION_DISTANCE * 1.5) {
     showHint(`${partID} 接近完成，还需移动 ${(dist - COMPLETION_DISTANCE).toFixed(2)} 米`);
   }
   ```

3. **调试工具**：
   ```javascript
   // 在场景中绘制目标位置的辅助线/球体
   const targetHelper = new THREE.Mesh(
     new THREE.SphereGeometry(0.1),
     new THREE.MeshBasicMaterial({ color: 0xff0000, transparent: true, opacity: 0.5 })
   );
   targetHelper.position.copy(target.position);
   scene.add(targetHelper);
   ```

### 问题 3：抓取时难以移动，可能自动切换抓取对象

#### 问题描述
抓取组件后，移动手势时组件响应迟缓，或意外切换到其他组件。

#### 当前实现状态
```javascript
// main.js:646-675 (抓取逻辑)
if (gesture.isPinching) {
  if (!isGrabbing) {
    // 寻找最近的组件
    availablePieces.forEach((piece) => {
      const dist = cursorSphere.position.distanceTo(piece.position);
      if (dist < 2.5 && dist < closestDist) {
        closestDist = dist;
        closestPiece = piece;
      }
    });
    if (closestPiece) {
      grabbedObject = closestPiece;
      isGrabbing = true;
    }
  } else if (grabbedObject) {
    // 移动被抓取的组件
    grabbedObject.position.copy(cursorSphere.position);
    checkSnap(grabbedObject);
  }
}
```

#### 问题根因分析
1. **手势识别不稳定**：
   - MediaPipe 的 `isPinching` 状态可能在移动过程中短暂变为 `false`
   - 导致 `isGrabbing` 被重置，重新寻找最近组件

2. **平滑移动导致延迟**：
   ```javascript
   // main.js:639-641
   smoothCursorX += (worldPos.x - smoothCursorX) * cursorSmoothAlpha;
   smoothCursorY += (worldPos.y - smoothCursorY) * cursorSmoothAlpha;
   smoothCursorZ += (worldPos.z - smoothCursorZ) * cursorSmoothAlpha;
   ```
   - `cursorSmoothAlpha` 值可能过小，导致光标移动滞后
   - 组件跟随光标，但光标移动慢，感觉"难以移动"

3. **抓取阈值过大**：
   - `dist < 2.5` 米可能过大，导致抓取到错误的组件
   - 多个组件接近时，可能频繁切换

4. **缺少"锁定"机制**：
   - 虽然代码中有 `grabbedObject` 锁定，但如果 `isPinching` 短暂失效，会重新进入抓取逻辑

#### 解决方案建议
1. **添加手势状态稳定性检查**：
   ```javascript
   let pinchStableCount = 0;
   const PINCH_STABLE_THRESHOLD = 3; // 需要连续 3 帧都是 pinching
   
   if (gesture.isPinching) {
     pinchStableCount++;
     if (pinchStableCount >= PINCH_STABLE_THRESHOLD && !isGrabbing) {
       // 开始抓取
     }
   } else {
     pinchStableCount = 0;
     // 只有在连续多帧都不是 pinching 时才松开
     if (isGrabbing) {
       releaseCount++;
       if (releaseCount > 5) { // 连续 5 帧都不是 pinching
         // 真正松开
       }
     }
   }
   ```

2. **优化平滑参数**：
   ```javascript
   // 抓取时使用更快的平滑速度
   const cursorSmoothAlpha = isGrabbing ? 0.4 : 0.2; // 抓取时更快响应
   ```

3. **降低抓取阈值**：
   ```javascript
   if (dist < 1.5 && dist < closestDist) { // 从 2.5 降低到 1.5
     closestDist = dist;
     closestPiece = piece;
   }
   ```

4. **添加"抓取锁定"机制**：
   ```javascript
   let grabLockTime = 0;
   const GRAB_LOCK_DURATION = 500; // 抓取后锁定 500ms，防止意外切换
   
   if (isGrabbing && grabbedObject) {
     grabLockTime = Date.now();
     // 在锁定期间，即使 isPinching 短暂失效，也不重新寻找组件
   }
   
   if (!isGrabbing || Date.now() - grabLockTime > GRAB_LOCK_DURATION) {
     // 允许重新抓取
   }
   ```

### 问题 4：快速拼好但位置都很错误

#### 问题描述
组件快速触发吸附，但实际位置与目标位置偏差较大，导致最终拼装结果不正确。

#### 当前实现状态
```javascript
// main.js:37
const SNAP_DISTANCE = 2.0; // ⚠️ 吸附阈值过大

// main.js:430-443
if (distance < SNAP_DISTANCE) { // 2.0 米内就吸附
  if (distance < 1.0 || angleDiff < SNAP_ANGLE_THRESHOLD) {
    shouldSnap = true; // 触发吸附
  }
}

// main.js:454-455
piece.position.copy(target.position); // 强制设置到目标位置
piece.quaternion.copy(target.quaternion); // 强制设置旋转
```

#### 问题根因分析
1. **吸附阈值过大**：
   - `SNAP_DISTANCE = 2.0` 米意味着组件距离目标 2 米就能吸附
   - 在 3D 场景中，2 米是相当大的距离，视觉上可能还很远

2. **角度检查被忽略**：
   - 当 `distance < 1.0` 时，完全忽略角度检查
   - 即使角度相差 90 度，只要距离 < 1.0 米就会吸附

3. **强制设置位置**：
   - 吸附时直接 `copy(target.position)`，没有平滑过渡
   - 用户可能感觉组件"瞬移"到错误位置

4. **缺少吸附前的验证**：
   - 没有在吸附前再次验证距离和角度
   - 可能在移动过程中，距离短暂 < 2.0 米就触发吸附

#### 解决方案建议
1. **降低吸附阈值**：
   ```javascript
   const SNAP_DISTANCE = 0.5; // 精确吸附，0.5 米
   const SNAP_ANGLE_THRESHOLD = Math.PI / 6; // 30 度
   
   if (distance < SNAP_DISTANCE) {
     // 必须同时满足距离和角度
     if (angleDiff < SNAP_ANGLE_THRESHOLD) {
       shouldSnap = true;
     }
   }
   ```

2. **添加吸附确认机制**：
   ```javascript
   let snapCandidate = null;
   let snapConfirmCount = 0;
   const SNAP_CONFIRM_FRAMES = 10; // 需要连续 10 帧都满足条件
   
   if (distance < SNAP_DISTANCE && angleDiff < SNAP_ANGLE_THRESHOLD) {
     if (snapCandidate === piece && snapCandidate === grabbedObject) {
       snapConfirmCount++;
       if (snapConfirmCount >= SNAP_CONFIRM_FRAMES) {
         // 确认吸附
         shouldSnap = true;
       }
     } else {
       snapCandidate = piece;
       snapConfirmCount = 1;
     }
   } else {
     snapCandidate = null;
     snapConfirmCount = 0;
   }
   ```

3. **平滑吸附动画**：
   ```javascript
   // 不使用直接 copy，而是平滑移动
   const snapSpeed = 0.1;
   piece.position.lerp(target.position, snapSpeed);
   piece.quaternion.slerp(target.quaternion, snapSpeed);
   
   // 当距离足够近时，才真正锁定
   if (piece.position.distanceTo(target.position) < 0.05) {
     piece.position.copy(target.position);
     piece.quaternion.copy(target.quaternion);
     piece.userData.isSnapped = true;
   }
   ```

4. **添加视觉反馈**：
   ```javascript
   // 当接近吸附时，显示提示
   if (distance < SNAP_DISTANCE * 1.5 && distance > SNAP_DISTANCE) {
     showSnapHint(`${partID} 接近目标，继续靠近以吸附`);
   }
   ```

## 七、总结

当前系统存在 4 个核心问题，主要集中在：
1. **阈值设置不合理**：吸附阈值过大（2.0米），完成验证过严（0.5米），导致矛盾
2. **事件处理不完善**：鼠标滚轮事件可能被拦截或未正确绑定
3. **手势识别不稳定**：缺少状态稳定性检查，导致意外切换
4. **缺少用户反馈**：没有视觉提示，用户难以判断距离和角度

**建议优先修复阈值统一和鼠标滚轮功能，这两项直接影响核心体验。**
