## 第 3 页 · 选题背景

**为什么选"斗拱"？**

- 斗拱 = 中国木构建筑的"灵魂"，集 **力学智慧、模数美学、礼制等级** 于一身
- 但它复杂、抽象、看不见摸不着 —— **课本上的一张黑白结构图，无法让人理解一根昂如何分担屋顶重量**
- 现有传播方式：博物馆静态展板 / 纪录片观看 / 文献阅读 —— **缺少"动手参与"**

**痛点定位**：

1. 传统古建知识"枯燥、抽象、难懂"
2. 实物保护要求高，公众无法触摸真斗拱
3. AR/VR 设备成本高，普及受限

**我们的回答**：**Web 端 + 普通摄像头 + 手势** = 零硬件门槛沉浸式体验

**视觉**：左侧老照片（古籍《营造法式》页面） + 右侧应用截图对比

## 第 5 页 · 核心创新点

### ① 手势 + 3D 解谜：零硬件沉浸式古建拼装

- MediaPipe Hands 实时识别捏合 / 张开
- 三阶段"磁吸"算法：远→中→近距离段不同的位置/旋转/缩放插值策略
- **让任何普通笔记本电脑都能成为"斗拱拼装工坊"**

### ② 数据驱动多关卡：可扩展 100+ 古建

- 自研校准工具 `calibrator.html` —— 美术师可视化标定每根构件的目标位置
- 一键导出 JSON，加入 `LEVELS` 数组即可上线新关卡
- **当前 2 关 → 未来 N 关**，零代码扩展

### ③ 双层级模型："整体—集合—部件"三级解析

- 整体：万春亭（外观）
- 集合：6 个主功能区（撩檐榑组 / 乳栿组 / 柱头枋组 ……）
- 部件：每个集合内 4–7 个细分构件（昂、拱、斗、枋）
- **用户可以从"看一栋楼"逐层下钻到"摸一根昂"**

**视觉**：三层"洋葱式"剖切图

## 第 12 页 · 关键技术亮点详解

### 亮点 1：三阶段磁吸算法


| 距离         | 行为                  | 体感         |
| ---------- | ------------------- | ---------- |
| > 1.5m     | 自由跟随光标              | 像在手里拖一块木头  |
| 0.2 - 1.5m | 位置/旋转/缩放向 target 插值 | 越靠近越像被磁石吸住 |
| < 0.2m     | 直接锁定到 target        | 松手就自动卡进    |


→ **解决了**手势识别本身有抖动，但用户能稳定吸附的核心难点

### 亮点 2：数据驱动关卡（LEVELS 数组）

- 美术师在 calibrator.html 鼠标拖动构件 → 一键导出 JSON
- 程序员把 JSON 粘贴进 `LEVELS[]` → 新关卡上线
- **未来扩展 N 个建筑无需改代码**

### 亮点 3：双层 3D 上下文（门户浮层 + 游戏全屏）

- 鉴赏 / 探微 = 浮层模式（保留门户上下文）
- 筑梦 = 全屏模式（沉浸游戏）
- 浮层内部独立 three.js 实例，避免与主游戏冲突

## 第 14 页 · 用户测试与迭代

**测试规模**：

- 10 名同学（本院非计算机背景） × 30 分钟体验 × 体验日记
- 5 名建筑学/历史专业学生 × 专家评审

**关键迭代**（节选）：

1. v1.0 → v1.5：手势"无心捏合"误触发 → 加入"持续 3 帧 + 距离阈值"双重判定
2. v1.5 → v2.0：第二关零件初始位置太挤 → 引入 `dockOverrides` 数据结构
3. v2.0 → v2.1：吸附失败感强 → 三阶段磁吸算法上线
4. v2.1 → v2.1.4：探微爆炸图加载抖动 → GLB 复用 + 性能优化
