## 1 摘要

本项目面向"中国古代建筑成就"主题，设计并实现了一个名为**"拾光筑梦"（Timeless Arches）**的 Web 端数字交互传承平台。平台以**斗拱**这一中国木构建筑的核心构件为切入点，通过**手势识别驱动的 3D 拼装解谜**（筑梦模式）、**爆炸图式部件级解析**（探微模式）、**9 栋真实古建的交互鉴赏**（鉴赏模式）三大核心功能，将抽象的木构力学知识转化为"指尖可玩"的沉浸体验。

技术上，本项目提出**三阶段磁吸算法**解决手势识别抖动下的精确吸附问题，构建**数据驱动的 LEVELS 关卡体系**实现零代码扩展，并自研**可视化校准工具（Calibrator）**让非程序员也能标定新关卡。

整站基于 **Vite + Three.js + MediaPipe Hands** 构建，无需安装任何软件、无需专用硬件，普通笔记本电脑 + 摄像头即可运行，实现了**零门槛的古建文化数字化传承**。

## 2 背景与选题动机

斗拱是中国传统木构建筑的"灵魂"构件，集力学智慧、模数美学、等级礼制于一身。从唐代含元殿的"如鸟斯革"到清代万春亭的"极致小木作"，斗拱技术历经千年演化，是中华建筑文化最具代表性的符号之一。

然而，当前公众对斗拱的认知存在三个核心痛点：

1. **抽象难懂**：课本上的一张结构图无法让人理解一根"昂"如何以杠杆原理分担屋顶重量；
2. **触不可及**：实物保护要求高，博物馆隔着玻璃罩，村野古建不允许触摸；
3. **设备门槛高**：现有 AR/VR 古建体验依赖头显设备，普及受限。

本项目的核心理念是：**用 Web + 普通摄像头 + 手势识别，把"看不见摸不着"的斗拱变成"指尖可拼"**。让任何拥有普通笔记本电脑的用户，无需安装任何软件，即可在 5 分钟内"亲手"组装一座千年斗拱，直观感受榫卯咬合、力流传导的木构智慧。

## 4 核心技术与算法

### 4.1 手势识别与 NDC 映射

本系统采用 **Google MediaPipe Hands** 进行实时手部关键点检测，提取 21 个手部关键点的 2D 坐标（归一化设备坐标，NDC）。

手势识别流程：

1. **摄像头捕获**：通过 `getUserMedia` API 获取视频流；
2. **关键点检测**：MediaPipe Hands 以约 30 FPS 输出 21 个关键点的 NDC 坐标；
3. **手势分类**：计算拇指尖（#4）与食指尖（#8）的欧氏距离，低于阈值判定为"捏合"（抓取），高于阈值判定为"张开"（释放）；
4. **抖动过滤**：采用"持续 3 帧 + 距离阈值"双重判定，避免无心捏合误触发；
5. **3D 坐标映射**：将 NDC 坐标通过自定义映射函数 `mapGestureTo3D()` 转换为 Three.js 世界坐标。

映射函数考虑了手势灵敏度、Y 轴偏移补偿和 Z 轴深度估计：

```
targetX = ndcX × SENSITIVITY_X
targetY = ndcY × SENSITIVITY_Y + Y_OFFSET
targetZ = lerp(Z_NEAR, Z_FAR, ndcDepth)
```

其中 `SENSITIVITY_Y = 5.0`，`Y_OFFSET = -0.5`，使光标 Y 范围覆盖 [-0.5, 4.5]，确保用户能触及备料架所有构件。

### 4.2 三阶段磁吸算法

手势识别的固有抖动（约 ±2-5 像素）使得精确放置构件非常困难。本项目提出**三阶段磁吸算法**，根据构件与目标位置的 XY 平面距离动态切换行为模式：

| 阶段 | XY 距离 | 位置行为 | 旋转行为 | 缩放行为 | 体感 |
|------|---------|----------|----------|----------|------|
| 远距离 | > 1.5m | 完全跟随光标 | 保持初始旋转 | 保持初始大小 | 自由拖动 |
| 中距离 | 0.2 ~ 1.5m | Z 轴 smoothstep 向目标插值 | quaternion slerp 向目标插值 | scale lerp 向目标插值 | 像被磁石吸引 |
| 近距离 | < 0.2m | 直接锁定到目标位 | 直接复制目标旋转 | 直接复制目标缩放 | 自动卡入 |

**图 2：三阶段磁吸算法示意图**

中距离插值使用 smoothstep 函数实现平滑过渡：

```
t = smoothstep(0.2, 1.5, dist)
piece.position.z = lerp(target.z, cursor.z, t)
piece.quaternion = slerp(target.quaternion, initialQuaternion, t)
piece.scale = lerp(target.scale, initialScale, t)
```

该算法的核心优势在于：**将手势识别的宏观抖动吸收到了交互体验内**。用户越靠近目标，抖动影响越小，最终在近距离段完全消除。释放时若距离 < 0.2m，构件自动吸附到精确位置，无需完美对齐。

### 4.3 数据驱动关卡体系

为实现"零代码扩展新关卡"，本系统设计了集中式关卡配置数组 `LEVELS[]`，每个关卡包含：

```javascript
{
  id: Number,                    // 关卡编号
  name: String,                  // 关卡显示名
  ghostPath: String,             // 幽灵参考模型路径
  pieceNames: String[],          // 构件名列表
  pieceLore: Object,             // 构件文化解说
  targetOverrides: Object,       // 每个构件的目标位置/旋转/缩放
  dockOverrides: Object,         // 备料架初始摆放位置
  environmentPath: String,       // 背景环境 GLB 路径
  environmentTransform: Object,  // 背景变换（缩放/位置/旋转）
  cameraPos / cameraTarget,      // 默认机位
  // ... 其他配置
}
```

配套自研 **Calibrator 校准工具**（`tools/calibrator.html`）：美术师在浏览器中可视化拖动构件到正确位置，一键导出 JSON，粘贴到 `LEVELS[]` 即完成新关卡上线。

**图 3：Calibrator 校准工具界面**

### 4.4 探微爆炸图与部件解析

探微模式加载万春亭的 6 个组件集合 GLB（与筑梦关卡共用同一套模型资源），按 `targetOverrides` 组装为完整姿态。用户点击"一键解体"后：

1. 计算 6 集合的几何中心作为爆炸原点；
2. 每个集合的辐射方向 = `(集合中心 - 爆炸原点).normalize()`；
3. 以 `explodeStrength` 参数控制辐射半径，使用 smoothstep 动画插值；
4. hover 时通过 Raycaster 检测命中的集合，设置 emissive 发光高亮；
5. 单击弹出右侧介绍卡，显示该集合包含的所有古建部件中文名及力学解析。

万春亭 6 个组件集合的部件命名：

| 集合 | 中文标题 | 包含部件 |
|------|----------|----------|
| 集合壹 | 撩檐榑组 | 撩檐榑、压槽枋、罗汉枋、替木 |
| 集合贰 | 乳栿与耍头组 | 乳栿、耍头里转、齐心斗、蚂蚱头、耍头、慢拱、令拱 |
| 集合叁 | 琴面昂铺作 | 柱头枋、㭼头、交互斗（隔口包耳）、琴面昂（下折假昂）、瓜子拱 |
| 集合肆 | 外檐铺作 | 柱头枋、琴面昂、散斗、交互斗 |
| 集合伍 | 栌斗与基座枋 | 泥道拱、栌斗（四耳栌斗）、阑额、普拍枋 |
| 集合陆 | 木栓 | 木栓 |

### 5.5 性能优化

在第二关（万春亭）开发中遭遇严重帧率下降问题，通过以下优化恢复流畅：

| 优化项 | 措施 | 效果 |
|--------|------|------|
| 阴影 | 大型静态模型禁用 castShadow | GPU 渲染负载 -40% |
| 提示特效 | 将"克隆整个 GLB"改为简单 RingGeometry | 面片数从数千降至 24 |
| 光标拖尾 | 降低粒子密度（4 帧 / 1 个，上限 8） | 粒子 Draw Call -75% |
| 模型管理 | 切关卡时 dispose 旧模型 + texture | 内存泄漏清零 |

## 7 总结与展望

本项目面向"中国古代建筑成就"主题，设计并实现了**"拾光筑梦"数字交互传承平台**。核心贡献包括：

1. 提出**三阶段磁吸算法**，在手势识别固有抖动下实现高成功率的构件精确吸附；
2. 设计**数据驱动的 LEVELS 关卡体系 + Calibrator 校准工具**，使新关卡扩展无需改动代码；
3. 构建**"鉴赏 - 探微 - 筑梦"三层递进**的交互体验架构，从宏观认知到微观操作，覆盖古建知识传播的全层次需求；
4. 实现 **9 栋真实古建的 Web 端 3D 交互**，覆盖民居、官署、皇宫、公共建筑 4 大类别，横跨唐 - 清 1200 年。

未来规划包括：扩展至 50+ 栋古建关卡、移动端触屏适配、WebXR AR 叠加现实、接入大模型 AI 实时解说等方向。
